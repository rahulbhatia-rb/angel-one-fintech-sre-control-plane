# Critical Incident Playbook

1. Establish customer impact and severity.
2. Assign an incident commander.
3. Freeze risky changes when appropriate.
4. Preserve evidence before random remediation.
5. Identify recent changes and dependency health.
6. Restore service using the safest mitigation.
7. Track timestamps and decisions.
8. Communicate status clearly.
9. Complete RCA only after stabilization.
10. Convert the root cause into a permanent corrective action and regression guard.

The key distinction is mitigation first, diagnosis second, permanent prevention third. A technically correct RCA is incomplete if the same failure mode can recur unchanged.
